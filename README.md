
# 🌸 NihongoMate — Learn Japanese, Your Way!

**NihongoMate** is an AI-powered Japanese language learning platform designed to make learning Japanese more accessible, interactive, structured, and effective for students around the world.

The platform aims to bring students and Japanese language teachers together through structured lessons, teacher-created video classes, JLPT-based learning paths, interactive practice, vocabulary development, pronunciation exercises, and personalized learning assistance.

NihongoMate focuses on providing a complete learning environment where students can learn Japanese at their own pace, follow a structured learning journey, interact with educational content, and monitor their progress.

## 🌐 Project Overview

Learning Japanese requires more than memorizing vocabulary and understanding grammar. Students need a structured learning path, consistent practice, listening exposure, pronunciation development, and opportunities to learn from experienced teachers.

NihongoMate is being developed to bring these learning activities together in one platform.

It is designed to support learners at different stages of Japanese language proficiency, from complete beginners to advanced learners preparing for the Japanese Language Proficiency Test (JLPT).

The platform provides two primary user experiences:

- **Students:** Learn Japanese through structured educational content, practice activities, and progress tracking.
- **Teachers:** Apply to become instructors and provide educational content, video classes, and learning support.

The long-term vision is to develop NihongoMate into a complete Japanese learning ecosystem supported by AI-powered educational assistance.

## ❗ Problem Statement

Many people interested in learning Japanese face difficulties when trying to follow a consistent and effective learning process.

Some common challenges include:

- Difficulty finding structured Japanese learning resources.
- Lack of personalized learning paths according to proficiency level.
- Limited opportunities for interactive learning and pronunciation practice.
- Difficulty identifying appropriate lessons for JLPT preparation.
- Learning resources scattered across different platforms.
- Limited access to teacher-led educational content.
- Difficulty tracking learning progress and identifying weak areas.
- Lack of personalized assistance when students encounter difficulties.

NihongoMate aims to address these challenges by providing an organized learning environment that combines structured lessons, teacher-created content, interactive practice, and future AI-powered assistance.

# ⚙️ How NihongoMate Works

NihongoMate is designed around a structured learning journey.

### Student Learning Journey

1. A student visits the NihongoMate website.
2. The student creates an account.
3. During registration, the student explicitly selects their preferred application display language: Japanese or English.
4. The student completes the onboarding process.
5. The student determines their current Japanese proficiency level through the placement process.
6. The platform identifies the student's appropriate JLPT level.
7. The student receives suitable learning recommendations.
8. The student accesses lessons, video classes, vocabulary, and pronunciation practice.
9. The student continues learning through interactive activities.
10. The platform tracks learning progress and displays relevant information on the dashboard.

### Teacher Journey

1. A teacher visits the platform.
2. The teacher selects the teacher application or registration option.
3. The teacher provides the required application information.
4. The application is checked against the platform's teacher eligibility requirements.
5. The application can be reviewed by the administration.
6. Approved teachers can access the teacher environment.
7. Teachers can create and manage educational content according to their permissions.

# 🎓 Student Module

The student module is the primary learning environment of NihongoMate.

It is designed to provide students with the tools needed to learn Japanese systematically.

### 1. Student Registration

Students can create accounts to access the learning platform.

The registration experience is designed to collect the necessary information while keeping the onboarding process simple.

An important requirement is the application display language selection.

Students must explicitly choose one of the following:

- English
- Japanese

Neither option should be selected automatically.

Students can change their application display language later through Settings.

### 2. Student Dashboard

The dashboard acts as the central location for student learning activities.

It is intended to display:

- Current JLPT level.
- Recommended lessons.
- Available classes.
- Learning progress.
- Vocabulary practice.
- Pronunciation activities.
- Recent learning activities.
- Personalized learning recommendations.

### 3. Placement Test

New students may not always know their current Japanese proficiency level.

The placement test is designed to help identify an appropriate starting point.

The test can evaluate knowledge of Japanese language concepts and help determine a suitable JLPT learning level.

After completing the test, students receive their placement result.

The placement result is used to guide their learning recommendations.

### 4. Lessons

The lessons section provides structured educational content.

Lessons are intended to cover different aspects of Japanese language learning, including:

- Hiragana.
- Katakana.
- Kanji.
- Vocabulary.
- Grammar.
- Sentence formation.
- Reading comprehension.
- Listening comprehension.

Lessons are organized according to the student's learning level.

### 5. Vocabulary Learning

Vocabulary is an essential part of learning Japanese.

NihongoMate aims to provide vocabulary learning activities that help students:

- Learn new Japanese words.
- Understand their meanings.
- Improve word recognition.
- Build vocabulary according to JLPT levels.
- Revise previously learned words.

### 6. Pronunciation Practice

Pronunciation practice helps students improve their spoken Japanese.

The platform aims to provide activities that help learners understand Japanese pronunciation and develop better speaking skills.

### 7. Progress Tracking

Students should be able to monitor their learning development.

Progress tracking is intended to include:

- Completed lessons.
- Learning activities.
- Vocabulary development.
- Practice history.
- Learning milestones.
- Overall learning progress.

# 📚 JLPT-Based Learning System

One of the central features of NihongoMate is its JLPT-based learning structure.

The Japanese Language Proficiency Test (JLPT) has five proficiency levels.

| Level | Description |
|---|---|
| N5 | Basic Japanese knowledge |
| N4 | Elementary Japanese knowledge |
| N3 | Intermediate Japanese knowledge |
| N2 | Upper-intermediate Japanese knowledge |
| N1 | Advanced Japanese knowledge |

### How JLPT-Based Recommendations Work

The platform uses the student's current JLPT level as an important factor when recommending educational content.

For example:

- An N5 learner receives beginner-level learning recommendations.
- An N4 learner receives elementary-level learning recommendations.
- An N3 learner receives intermediate-level learning recommendations.
- An N2 learner receives upper-intermediate learning recommendations.
- An N1 learner receives advanced-level learning recommendations.

The purpose is to ensure that students receive content appropriate to their current proficiency.

Classes and videos can be available in Japanese or English, depending on the content.

NihongoMate is intended for students worldwide.

Therefore, application language preferences are an important part of the user experience.

### Student Application Display Language

During registration, students must explicitly select their preferred application display language.

Available options:

1. English
2. Japanese

Important requirements:

- Neither language is preselected.
- Students must make an explicit selection.
- Students can change their selection later through Settings.
- Students are not asked to select a separate explanation language.
- Students are not asked to provide their time zone during registration.

### Learning Content Language

The language used by the application interface and the language used in educational content are separate concepts.

Students can access classes and videos in either Japanese or English.

This allows students to learn Japanese through resources that match their learning preferences.

**Data**

This organization helps maintain a clean and scalable frontend codebase.

# 🚀 Installation and Setup

Follow these steps to run NihongoMate on your local machine.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- Visual Studio Code (recommended)

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/NihongoMate.git
```

Replace `YOUR-USERNAME` with the GitHub account that owns the repository.

### 2. Navigate to the Project Directory

```bash
cd NihongoMate
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Vite will provide a local development URL in the terminal.

Usually:

```text
http://localhost:5173
```

Open the URL in your browser to access NihongoMate.
